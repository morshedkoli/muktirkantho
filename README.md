# 📰 Muktirkantho — Modern Digital News Publishing & Media Portal

A digital news portal and content publishing system built with **Next.js**, **Prisma ORM**, **Cloudinary**, and **Radix UI**. Engineered for rapid breaking news dissemination, multimedia journalism, and editorial workflows.

---

## 🌟 Key Features

- **⚡ Real-Time Editorial Pipeline**: Instant publishing of breaking headlines with category tagging (National, International, Politics, Sports, Tech).
- **📸 High-Resolution Media Management**: Automatic image optimization, lazy loading, and CDN delivery powered by Cloudinary.
- **🎨 Accessible Reader UI**: Dynamic dark mode, responsive layouts, and typography optimized for Bengali script readability.
- **🔍 Full-Text Article Search**: Fast indexing and retrieval across archives and trending tags.

---

## 🚀 Setup & Launch

```bash
git clone https://github.com/morshedkoli/muktirkantho.git
cd muktirkantho
npm install
npx prisma db push
npm run dev
```
